# WhatsApp AI-бот для автомойки

Клиент пишет в WhatsApp → бот отвечает сам (мойка, полировка, часы, адрес).
Если клиент хочет записаться — заявка автоматически уходит менеджеру в Телеграм.

## Что нужно (уже должно быть готово)
- xAI (Grok) API ключ
- GREEN-API: idInstance + apiTokenInstance (номер привязан по QR-коду)
- Telegram Bot Token (от @BotFather)
- Telegram Chat ID (куда слать заявки)

## Шаг 1. Настроить проект
```bash
cp .env.example .env
```
Откройте `.env` и впишите туда все 4 ключа, а также:
- `SYSTEM_PROMPT` — впишите реальные цены на мойку/полировку, часы работы, адрес
- `BOOKING_KEYWORDS` — слова, по которым бот поймёт, что клиент хочет записаться (можно оставить как есть или дополнить)

## Шаг 2. Установить и запустить
```bash
npm install
npm start
```

## Шаг 3. Прокинуть вебхук наружу (для теста)
```bash
ngrok http 3000
```
Скопируйте адрес вида `https://xxxx.ngrok-free.app`.

## Шаг 4. Указать вебхук в личном кабинете GREEN-API
```
webhookUrl = https://xxxx.ngrok-free.app/webhook
incomingWebhook = yes
```

## Шаг 5. Проверка
Напишите с личного номера на подключённый номер автомойки:
- Обычный вопрос ("сколько стоит мойка?") → бот отвечает сам
- "хочу записаться на мойку завтра в 15:00" → бот отвечает клиенту + заявка прилетает вам в Телеграм

## Список заявок на запись
Каждая заявка от клиента (кроме уведомления в Телеграм) сохраняется в общий список.
Посмотреть список можно в браузере по адресу:
```
http://localhost:3000/bookings?key=moika123
```
(если бот размещён на постоянном сервере — вместо `localhost:3000` подставьте адрес сервера).

`moika123` — секретный ключ из файла `.env` (`BOOKINGS_SECRET`), поменяйте на своё слово, чтобы никто чужой не смог открыть список.

## Для постоянной работы (не только теста)
ngrok — временное решение для проверки. Чтобы бот работал круглосуточно, разместите его на постоянном сервере (VPS, Railway, Render) вместо своего компьютера с ngrok.

## Важно
Подключение через GREEN-API (по QR-коду) — неофициальный способ, использует тот же механизм, что WhatsApp Web. Широко используется малым бизнесом, но формально не одобрено Meta — при большом объёме сообщений есть риск блокировки номера.
